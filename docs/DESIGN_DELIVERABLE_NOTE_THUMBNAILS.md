### SVG → PNG 変換手順

サムネイルをnoteにアップロードするため、SVGをPNG (1280x670) に変換する必要がある。

**方法1: ブラウザ使用 (推奨)**
1. SVGファイルをブラウザで開く
2. DevToolsのスクリーンショット機能で1280x670にキャプチャ
3. または `html2canvas` / `dom-to-image` ライブラリで変換

**方法2: CLI (ImageMagick)**
```bash
# ImageMagickインストール済みの場合
convert -background none -size 1280x670 input.svg output.png
```

**方法3: Figma / Canva**
- SVGをインポートして1280x670で書き出し
- フォント差し替えが必要な場合はこの方法が最も柔軟

## 8. MEDIUM/LOW 警告 (コード変更なし)

- **[MEDIUM]** SVGファイルのフォント (`Noto Sans JP`, `Playfair Display`) はローカル環境依存。PNG変換時にフォントが利用可能であることを確認すること。Figma/Canvaでの書き出しが最も安全。
- **[MEDIUM]** note推奨サイズは 1280x670 だが、実際にはアスペクト比 1.91:1 で表示される場合がある。上下端 10px のセーフゾーンを意識すること（現テンプレートは 48px マージンで対応済み）。
- **[LOW]** ウォーターマークのスートシンボルはフォント依存で表示が異なる場合がある。最終PNG確認時にチェック。
- **[LOW]** タグラインの文字色 `#4a5245` はコントラスト比が低め (2.1:1) だが、装飾要素のため WCAG 基準外。
