## 4. 推奨アクション

### 即時対応（CRITICAL）

1. **現行CSV全廃・新規作成**: 既存CSVは架空IDが大半のため、参考資料に格下げし、ゼロからリストを再構築する

2. **X API v2を使用した実データ取得**: 以下のスクリプトを開発し、実際のXデータに基づくリストを生成する
   - ポーカー関連キーワードでユーザー検索
   - `public_metrics.followers_count < 1000` でフィルタ
   - プロフィール（bio）を正確に取得
   - アカウント凍結・削除チェック

3. **検索キーワード案**（フォロワー1000未満のユーザー発掘用）:
   - `ポーカー`, `poker`, `テキサスホールデム`, `NLH`
   - `ポーカー初心者`, `ポーカー勉強中`, `ポーカー始めました`
   - `アミューズメントポーカー`, `ポーカーバー`
   - `GTO`, `ハンドレンジ`, `プリフロップ`
   - 地方店舗名、大学サークル名

### 短期対応（HIGH）

4. **カテゴリ再定義**: ランブック定義のカテゴリに正確に分類
5. **バリデーションルール実装**: QA部門（雪花）のチェックリストに基づく自動検証
6. **インフルエンサー除外基準の明文化**: フォロワー1000人未満をランブックに追記

### CSV再構築時のターゲット層

CEOの「インフルエンサーは含めたくない」要件に基づき、以下を主要ターゲットとする:

| ターゲット層 | 説明 | 期待件数 |

## 5. Dev部門への要件仕様

### X API v2 バッチスクリプト要件

```
入力: ポーカー関連キーワードリスト
処理:
  1. GET /2/users/search でキーワード検索
  2. followers_count < 1000 でフィルタ
  3. 各ユーザーのbio, name, username, public_metrics取得
  4. 凍結/削除アカウント除外
  5. 重複排除
出力: BOM付きUTF-8 CSV
カラム: @ユーザーID, ユーザー名, プロフィール概要, フォロワー数, カテゴリ, ステータス
```

**注意**: ランブックのカラムに「フォロワー数」を追加することを推奨（フィルタ要件の検証容易化のため）

### レートリミット対策
- X API v2 Basic: 15リクエスト/15分
- バッチ処理にsleep挿入
- 429レスポンスでexponential backoff
