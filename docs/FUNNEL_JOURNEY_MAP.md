# Poker SNS ユーザー導線設計書 — チャネル別ジャーニーマップ

> 作成: 常闇 (Planning) / 2026-03-02
> 目的: 外部SNS → poker_sns → 課金 の導線を最適化し、月100万円売上を達成する

---

## 1. 現状ファネル分析

### 1.1 現在の導線（As-Is）

```
[外部SNS] → /lp → / (AuthForm) → 登録 → メール認証 → フィード利用 → /settings で課金
```

**致命的な課題:**
| # | 課題 | 影響度 |
|---|------|--------|
| 1 | LP→登録の CTA が全て `/` へ遷移。UTM パラメータ未保持 | 流入元の計測不能 |
| 2 | 専用プライシングページ不在。課金導線が `/settings` のみ | 課金CVR低下 |
| 3 | Google Analytics / 計測タグ未設置 | ファネル改善の PDCA 不可能 |
| 4 | OGP が汎用的。チャネル別の訴求なし | CTR 低下 |
| 5 | 登録後の課金誘導（オンボーディング）なし | Free→Premium 転換率低下 |
| 6 | アフィリエイトクリックと課金の紐付けなし | パートナーへの成果報告不可 |

### 1.2 売上目標の逆算

月100万円 = Premium ¥980/月 × **1,021人**（純サブスク）
or Premium ¥980 × 500人 + 広告収入 ¥20万 + アフィリエイト ¥30万

**必要ファネル数値（保守的想定）:**
```
月間LP訪問: 50,000
LP → 登録CVR: 8% = 4,000人/月 新規登録
登録 → 月間アクティブ: 50% = 2,000人
アクティブ → Premium: 5% = 100人/月 新規課金
累積12ヶ月: ~800人 Premium + 広告 + アフィリエイト
```

## 4. UTM パラメータ設計

### 4.1 パラメータ体系

| パラメータ | 値の例 | 用途 |
|-----------|-------|------|
| `utm_source` | x, note, youtube, google, direct | 流入元プラットフォーム |
| `utm_medium` | social, article, video, search, cpc | メディア種別 |
| `utm_campaign` | launch_2026q1, hand_review, gto_series | キャンペーン名 |
| `utm_content` | hero_cta, footer_link, bio_link | CTA位置の識別 |

### 4.2 UTMフロー設計

```
1. LP到着時: URLからUTMパラメータ抽出 → sessionStorage保存
2. 登録画面遷移: sessionStorageからUTM読み込み → hidden fieldに設定
3. POST /auth/register: bodyにutm_source, utm_medium, utm_campaign含める
4. Userテーブル: referralSource, referralMedium, referralCampaign カラム追加
5. 課金時: SubscriptionEventにUTM紐付け → チャネル別ROAS計測可能
```

## 8. 桃鈴・宝鐘向け 実装仕様サマリ

### P0: UTMパラメータ保持（フロントエンド）

**ファイル:** `frontend/src/app/lp/page.tsx`, `frontend/src/contexts/AuthContext.tsx`

```
// LP到着時
const params = new URLSearchParams(window.location.search)
const utm = {
  source: params.get('utm_source'),
  medium: params.get('utm_medium'),
  campaign: params.get('utm_campaign'),
  content: params.get('utm_content')
}
if (utm.source) sessionStorage.setItem('utm', JSON.stringify(utm))

// 登録API呼び出し時
const stored = JSON.parse(sessionStorage.getItem('utm') || '{}')
POST /auth/register { ...formData, referralSource: stored.source, ... }
```

### P0: /pricing ページ

**ルート:** `frontend/src/app/pricing/page.tsx`
- Free vs Premium の2カラム比較
- Premium CTA → `/subscriptions/checkout` API呼び出し
- FAQ セクション（解約、支払い方法、返金）
- LP、ナビバー、設定ページからリンク

### P0: 文字数制限モーダル

**ファイル:** `frontend/src/app/page.tsx`（投稿フォーム）
- 280文字到達時にモーダル表示
- 「Premiumなら1,000文字まで投稿可能」
