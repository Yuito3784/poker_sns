## 2. ブランドトーン & ボイス

### トーン原則

| 原則 | 説明 | NG例 |
|------|------|------|
| **プロフェッショナル** | ポーカープレイヤーとして対等な目線で話す | 「すごいサービスです!」のような過剰な売り込み |
| **簡潔** | 要点を先に、説明は後に | 長文で挨拶から始める冗長なメッセージ |
| **価値提示型** | 相手にとってのメリットを先に提示する | 自社サービスの機能羅列 |
| **敬意** | 相手の活動への理解・リスペクトを示す | テンプレ感が出る一律配信的な文面 |

### ボイス特性
- **一人称:** 「私たち」（チーム感）or 省略
- **敬語レベル:** 丁寧語（です・ます）。過度な謙譲語は使わない
- **禁止表現:** 絵文字の多用、「!」の連続、「(笑)」「w」等のカジュアル表現
- **許可表現:** スペードマーク（♠）をブランドアイコンとして1箇所のみ使用可

## 3. テンプレート構成

### 構成ルール（4パート構成）

```
[1. パーソナライズ導入] — 相手の活動への言及（1文）
[2. サービス紹介] — poker_snsの価値提案（1-2文）
[3. 相手へのメリット] — カテゴリ別のベネフィット（1文）
[4. CTA] — 具体的な次のアクション（1文）
```

### 文字数ガイドライン
- **DM全体:** 200〜300文字以内（X DMの可読性を考慮）
- **各パート:** 1-2文を厳守

## 6. 送信運用ルール

### タイミング
- **送信時間帯:** 平日 12:00-13:00 / 19:00-22:00（ポーカープレイヤーのアクティブ時間帯）
- **送信間隔:** 1日最大10件（スパム判定回避）
- **フォローアップ:** 初回DMから7日後に未返信の場合、1回のみリマインド可

### フォローアップテンプレート

```
{ユーザー名}さん

先日ご連絡した♠ Poker SNSの件、
お忙しいところ失礼いたしました。

もしご興味がありましたら、
いつでもお気軽にお試しください。
pokersns.com
```

### 禁止事項
- 同一アカウントへの3回以上のDM送信
- 返信で「不要」と言われた場合の再連絡
- 深夜帯（23:00-8:00）の送信
- 複数アカウントからの同一人物への並行アプローチ

## 7. 効果測定指標

| 指標 | 計測方法 | 目標値 |
|------|----------|--------|
| DM開封率 | X既読表示 | 60%以上 |

| 登録転換率 | 登録数/訪問数 | 15%以上 |

### UTMパラメータ付きURL形式
```
pokersns.com?utm_source=x&utm_medium=dm&utm_campaign=outreach_v1&utm_content={category}
```
