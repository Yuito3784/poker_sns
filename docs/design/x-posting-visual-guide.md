## 3. X投稿時の注意事項

### URLとOGPカードの関係
- **LP URL推奨:** X投稿時はLPページURLを使用すること。LP専用OGP画像が「日本初のポーカー特化SNS」バッジ+CTA付きで表示され、コンバージョン訴求が最も強い
- **URLはツイート末尾に配置:** Xのカード展開はURL位置に依存しない。末尾に置くことで本文の可読性を確保

### 画像キャッシュ
- X（Twitter）はOGP画像を独自にキャッシュする
- 画像変更後は [Card Validator](https://cards-dev.twitter.com/validator) でキャッシュ更新が必要
- 当サーバー側キャッシュ: `max-age=3600, s-maxage=86400`

### テキストと画像の一貫性
- 投稿文内のキーフレーズとOGP画像内のテキストを一致させる
- 例: 投稿文で「日本初のポーカー特化SNS」と記載 → LP OGP画像にも同バッジあり

## 4. LP専用OGP画像 改善実装

**ファイル:** `frontend/src/app/lp/opengraph-image.tsx`

### デザイン仕様
- **レイアウト:** 中央揃え縦積み
- **バッジ:** 「日本初のポーカー特化SNS」（ゴールド枠ピル型）
- **ロゴ:** ♠ Poker SNS（72px + 64px）
- **タグライン:** 「ハンドレビュー・GTO戦略の議論・プレイヤーコミュニティで上達を加速」
- **フィーチャーチップ:** 「ハンドを共有」「戦略を議論」「仲間と繋がる」
- **CTA:** 「無料で今すぐ始める」（ゴールドボタン、ダークテキスト）
- **背景:** ブランド準拠グラデーション + スート透かし

### トップOGP画像との差分
| 要素 | トップ | LP |
|------|--------|-----|
| バッジ | なし | 「日本初のポーカー特化SNS」 |
| タグライン | 「共有して、もっと上手くなる」 | 「ハンドレビュー・GTO...上達を加速」 |
| チップ文言 | 記録/議論/磨く | 共有/議論/繋がる |
| CTAボタン | なし | 「無料で今すぐ始める」 |

→ LPはコンバージョン特化、トップは認知特化の設計。
