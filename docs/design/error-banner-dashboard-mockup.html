1. Status Color Tokens

StateBackgroundBorderTextIcon
Error rgba(176,48,48,0.15) #b03030 #e85c5c #b03030
Retry / In Progress rgba(201,168,76,0.12) #9a7c35 #c9a84c #c9a84c
Success / Complete rgba(76,160,90,0.12) #3a7a42 #5cb868 #4ca05a
Design Note: Error uses existing toast error color (#b03030). Retry/in-progress reuses the brand gold (#c9a84c) to match the premium feel. Success introduces green which is complementary to the dark green surface. All background colors use low-alpha to maintain The Felt Table dark atmosphere.

Mobile: Action button wraps to full-width below content on <640px.

Dashboard Layout: Single card on #131a14 surface, border-radius: 12px, padding: 24px, border: 1px solid #1f2a1e.
Stat Grid: 4-column on desktop, 2-column on mobile. Cards use #192118 elevated surface.
Progress Bar: 6px height, segmented fill (done=green, running=gold, error=red).
Task List: Left dot indicator, right-aligned timestamp in monospace.
Placement: Admin/operator view - accessible from sidebar or /admin/tasks route.
Real-time: WebSocket or 5s polling for live updates. Dot indicators pulse for active tasks.
