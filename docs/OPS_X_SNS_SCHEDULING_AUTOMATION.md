## Operations Team (白上) / 2026-03-07

---

## 1. 課題と方針

CEOから「毎日複数回きちんとツイート」の要件あり。人力での継続運用は破綻リスクが高いため、スケジューラー導入と投稿キュー運用フローを初期段階で確立する。

### 1.1 運用破綻リスク分析

| リスク | 影響 | 対策 |
|--------|------|------|
| 投稿忘れ・時間ずれ | インプレッション低下、アルゴリズム不利 | スケジューラーで事前予約 |
| 属人化 | 担当者不在時に運用停止 | 1週間分バッチ作成→予約投稿 |
| 質のばらつき | ブランド毀損 | テンプレート＋チェックリスト |
| 最適時間帯の逸失 | エンゲージメント低下 | データ駆動の投稿時間最適化 |

### 2.2 推奨: SocialDog（Businessプラン）

**選定理由:**
1. **日本語ネイティブUI** — 日本市場向けポーカーSNSと親和性が高い
2. **AI投稿時間最適化** — フォロワーのアクティブ時間を自動分析
3. **フォロワー分析** — フォロー/アンフォロー追跡でKPI計測に活用
4. **コスト効率** — ¥1,480/月で必要機能を網羅（Hootsuite比で1/8）
5. **スレッド投稿対応** — ポーカー解説等の長文コンテンツに必要

## 3. 投稿キュー運用フロー

### 3.1 週次バッチ作成フロー

```
毎週月曜 AM
  ├─ 1. 先週のKPIレビュー（インプレッション、エンゲージメント率）
  ├─ 2. 今週のトピック選定（ポーカーニュース、Tips、サービス告知）
  ├─ 3. 投稿原稿作成（テンプレートベース、7日×3-5本=21-35本）
  ├─ 4. QAチェック（チェックリスト適用）
  └─ 5. SocialDogに一括予約登録
```

### 3.2 1日の投稿スケジュール（推奨）

| 時間帯 | 投稿カテゴリ | 根拠 |
|--------|-------------|------|
| 07:30 | モーニングTips / ポーカー名言 | 通勤時間帯、高インプレッション |
| 12:15 | ニュース・トピック共有 | 昼休み、エンゲージメント最高帯 |
| 18:30 | サービス紹介・機能紹介 | 帰宅時間帯、CTA効果大 |
| 21:00 | ハンド解説・戦略コンテンツ | 夜のリラックスタイム、保存率高 |
| 23:00 | (任意) 軽いネタ・アンケート | 深夜ポーカープレイヤー層 |

### 3.3 投稿カテゴリ配分

| カテゴリ | 週間比率 | 例 |
|---------|---------|-----|
| **ポーカーTips/戦略** | 30% | プリフロップレンジ、ポジション解説 |
| **ニュース/トピック** | 20% | トーナメント結果、業界ニュース |
| **サービス紹介/CTA** | 20% | poker_sns新機能、登録促進 |
| **コミュニティ連携** | 15% | ユーザー投稿リポスト、Q&A |
| **エンタメ/ネタ** | 15% | ポーカーミーム、アンケート、名言 |

## 5. 緊急対応・障害時フロー

### 5.1 投稿失敗時

```
SocialDog投稿失敗
  ├─ 自動リトライ（SocialDog内蔵）
  ├─ 3回失敗 → 手動投稿にフォールバック
  └─ X API障害の場合 → 復旧後にまとめ投稿（間隔15分以上）
```

### 5.2 炎上・ネガティブ対応

| レベル | 基準 | 対応 |
|--------|------|------|
| 注意 | ネガティブリプ1-3件 | 丁寧に返信、必要に応じ投稿修正 |
| 警戒 | ネガティブ5件以上 or 拡散傾向 | 該当投稿削除検討、CEO報告 |
| 危機 | メディア取り上げ or 大規模炎上 | 全投稿停止、公式声明ドラフト、CEO判断 |

## 6. 自社自動投稿API連携（Phase 2）

Phase 1で投稿パターンが確立した後、poker_snsバックエンドから直接X APIへ投稿する自動化を実装する。

### 6.1 対象コンテンツ（自動投稿候補）

| コンテンツ | トリガー | 投稿内容 |
|-----------|---------|---------|
| 人気投稿 | いいね数が閾値超過 | 投稿引用＋poker_snsリンク |
| 新規ユーザー数 | 日次集計 | 「本日{N}名が参加！」 |
| トレンドハッシュタグ | アプリ内トレンド更新 | トレンドまとめツイート |

### 6.2 技術連携

- 既存の `ops-sns-autopost-job-scheduler.md` のpg-boss設計をそのまま活用
- X API Free Tier (500件/月) でMVP十分 → 1日3-5件 × 30日 = 90-150件
- DevチームへのAPI実装依頼はPhase 2開始時に発行
