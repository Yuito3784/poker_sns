# Design UI Specification: 5 Revenue Features

> Design Lead: 宝鐘 (百鬼)
> Date: 2026-03-05
> Theme: "The Felt Table" Dark Luxury (#0d1009 + #c9a84c Gold CTA)

## 共通デザイン原則

### カラートークン（全機能共通）
| Token | Value | Usage |
|-------|-------|-------|
| Background | `#0d1009` | Page / overlay backdrop |
| Surface | `#151c15` | Card, modal, sheet |
| Surface Elevated | `#1c241c` | Hover state, dropdown |
| Border | `#2a3828` | Default border |
| Border Active | `#3a4a38` | Hover / focus border |
| Gold Primary | `#c9a84c` | CTA button bg, accent |
| Gold Dim | `#9a7c35` | Secondary accent, icon |
| Text Primary | `#ddd6c8` | Body text |
| Text Secondary | `#7a7260` | Subtitle, metadata |
| Text Muted | `#4a5245` | Disabled, placeholder |
| CTA Text | `#0d1009` | Button text on gold bg |

### タイポグラフィ
- Heading: Playfair Display (serif)
- Body: Noto Sans JP + Geist Sans
- Mono: Geist Mono (amounts, codes)

### 共通コンポーネント
- **CTAボタン**: `background: #c9a84c; color: #0d1009; border-radius: 8px; font-weight: 600`
- **モーダル**: `background: #151c15; border: 1px solid #2a3828; border-radius: 12px; box-shadow: 0 8px 32px rgba(0,0,0,0.6)`
- **金額表示フォント**: Geist Mono, `color: #c9a84c`

```
│  ┌─────────────────────────────────┐    │

│  └─────────────────────────────────┘    │
│                                         │

│                                         │
│  手数料: ¥50（10%）  受取額: ¥450       │
│                                         │
└─────────────────────────────────────────┘
```

**仕様:**
- プリセット金額ボタン: 4つ (`¥100`, `¥500`, `¥1,000`, `¥3,000`)
- 選択状態: `border: 2px solid #c9a84c; background: rgba(201,168,76,0.12)`
- 未選択: `border: 1px solid #2a3828; background: #151c15`
- カスタム入力: Geist Mono font, 数値のみ, `min: 100, max: 50000`
- CTAボタン: 金額を動的表示 `♠ チップを送る ¥{amount}`
- 手数料表示: Text Secondary, Geist Mono for numbers
- モーダルサイズ: `max-width: 420px`
- トリガー: PostItem内のチップアイコンボタン（♠マーク）

### 1.2 チップアニメーション演出

```css
/* チップ送信成功アニメーション */
@keyframes chip-fly {
  0%   { transform: translateY(0) scale(1); opacity: 1; }
  40%  { transform: translateY(-60px) scale(1.2); opacity: 1; }
  100% { transform: translateY(-120px) scale(0.6); opacity: 0; }
}

@keyframes chip-sparkle {
  0%   { box-shadow: 0 0 0 0 rgba(201,168,76,0.4); }
  50%  { box-shadow: 0 0 20px 8px rgba(201,168,76,0.3); }
  100% { box-shadow: 0 0 0 0 rgba(201,168,76,0.0); }
}

.animate-chip-fly {
  animation: chip-fly 0.8s cubic-bezier(0.34, 1.56, 0.64, 1) forwards;
}

.animate-chip-sparkle {
  animation: chip-sparkle 0.6s ease-out;
}
```

**演出フロー:**
1. CTAクリック → ボタンが `chip-sparkle` で光る
2. ♠チップアイコンが `chip-fly` で上方へ飛ぶ（0.8s）
3. 成功トースト: `"¥500 のチップを送りました"` (gold accent border)
4. 投稿カード上にチップ総額バッジ更新

## レスポンシブ対応

### ブレークポイント
| Name | Width | Layout |
|------|-------|--------|
| Mobile | < 640px | Single column, full-width cards |
| Tablet | 640-1024px | 2-column grid |
| Desktop | > 1024px | 3-column grid + sidebar |

### Mobile固有調整
- モーダル → フルスクリーンのボトムシート (slide-up)
- 金額プリセット → 横スクロール (2行→1行)
- タッチターゲット: 最小 44x44px (WCAG準拠)
- BottomNavに「♠」マーケットプレイスタブ追加検討
