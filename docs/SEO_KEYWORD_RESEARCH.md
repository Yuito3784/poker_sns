## 4. 内部リンク戦略

LP → 各ハッシュタグページへの内部リンクを追加することで、ハッシュタグページのSEO強化とクロール促進を図る。

**推奨内部リンク構造**:
```
/lp
  └─→ /explore (「投稿を見る」CTA)
  └─→ /hashtag/GTO (「GTO学習」セクション)
  └─→ /hashtag/ハンドレビュー (「ハンドレビュー」セクション)
  └─→ /partners (「パートナー」セクション)

/explore
  └─→ /hashtag/[人気タグ] (トレンドタグリンク)

/post/[id]
  └─→ /profile/[author] (著者プロフィールリンク)
  └─→ /hashtag/[tag] (ハッシュタグリンク)
```
