## 3. 段階的立ち上げスケジュール

3チャネル同時に全力運用するとCEOの負荷が過大になるため、段階的に立ち上げる。

### Phase 1: 基盤構築 (1-2ヶ月目)

| 週 | YouTube | note | 営業 |
|----|---------|------|------|
| W1 | チャンネル開設、ブランドアセット適用 | (既存運用継続) | ターゲットリスト30件作成 |
| W2 | 初回動画 撮影→編集→公開 | (既存運用継続) | アプローチ開始（10件/週） |
| W3 | 週1本ペース確立 | (既存運用継続) | フォローアップ開始 |
| W4 | KPI初計測・チューニング | (既存運用継続) | 月次レビュー実施 |

**Phase 1 完了条件:**
- YouTube: 動画4本公開、KPI収集パイプライン稼働
- note: 既存3日おきペース安定維持
- 営業: 30件アプローチ完了、商談3件以上

### Phase 2: 安定運用 (3-4ヶ月目)

| チャネル | 目標 |
|---------|------|
| YouTube | 週2本、登録者100人、poker_sns流入 週50人 |
| note | 3日おき + 有料記事月1本開始 |
| 営業 | 月30件アプローチ、成約1件/月 |

### Phase 3: 拡大・収益化 (5-6ヶ月目)

| チャネル | 目標 |
|---------|------|
| YouTube | 週3-5本、収益化条件達成（登録者1,000 + 再生4,000h） |
| note | 有料記事月2本、月間売上3万円 |
| 営業 | 成約2件/月、月間売上20万円 |

## 4. 収益目標への貢献マッピング

プロジェクト核心目標「月間売上100万円」に対する各チャネルの貢献見込み。

| 収益源 | Phase 2目標 (月間) | Phase 3目標 (月間) | 備考 |
|-------|-------------------|-------------------|------|
| プレミアム会員 | ¥50,000 | ¥200,000 | 既存チャネル |
| アフィリエイト | ¥30,000 | ¥100,000 | 既存チャネル |
| YouTube広告収益 | ¥0 | ¥10,000 | 収益化条件達成後 |
| note有料記事 | ¥5,000 | ¥30,000 | Phase 2から開始 |
| 営業（法人契約） | ¥100,000 | ¥200,000 | 最大の売上貢献源 |
| **合計** | **¥185,000** | **¥540,000** | Phase 3で54万円/月 |

**100万円達成への追加施策（Phase 4以降）:**
- 法人契約の大型案件獲得（広告出稿パッケージ等）
- YouTube案件動画・スポンサード
- poker_snsのホワイトラベル提供
- ポーカー大会スポンサーシップ仲介
