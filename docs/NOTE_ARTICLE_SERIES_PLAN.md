## 1. 連載コンセプト

### 1.1 タイトル案

**メインタイトル**: 「エンジニア1人で月100万を目指す — ニッチSNS開発の全記録」

**サブタイトル候補**:
- 「ポーカーSNSを作って売上100万円を目指すリアルな話」
- 「未経験からWebサービスで稼ぐまでの全プロセス公開」

### 1.2 ターゲット読者

| セグメント | ペルソナ | 刺さるフック |
|-----------|---------|------------|
| 副業エンジニア | 本業+αで月10万稼ぎたい20-30代 | 「1人で作って1人で運用する」リアリティ |
| プログラミング学習中 | スクール卒・独学でポートフォリオ欲しい | 「実際のプロダクトの作り方」 |
| 非エンジニア起業志望 | アイデアはあるが開発方法がわからない | 「どこから始めるか」の具体手順 |
| 既存サービス運営者 | マネタイズに苦戦中 | 収益化の3本柱戦略 |

### 1.3 差別化ポイント

- **実プロダクトのコード・設計図を公開** — 理論ではなく実践ベース
- **マネタイズ3本柱**(広告/アフィリエイト/サブスク)を全て1サービスで実装した事例
- **セキュリティ・運用まで踏み込む** — 「作って終わり」ではない本番運用の話
- **poker_snsへの流入導線** — 読者がサービスを知り、使ってみるきっかけに

### 1.4 マネタイズ連動

| チャネル | 施策 |
|---------|------|
| note記事内CTA | poker_sns登録リンク (UTM付き) |
| 有料マガジン化 | 連載10本目以降で有料化検討 (月額980円 or 単品300円) |
| poker_sns Premiumへの誘導 | 「実際に作ったサービスのPremium機能」として紹介 |
| アフィリエイト | 記事内でAWSやStripeの紹介リンク |
| コンサル/メンター | 連載後半で個別相談メニュー開設 |

## 3. 第1回記事の構成案（ドラフト用）

### タイトル: 「なぜポーカー専用SNSを作ったのか — The Felt Table の誕生秘話」

**想定文字数**: 約4,000字

#### 構成

```
■ 導入（400字）
- 自己紹介（簡潔に）
- 「ポーカー専用SNS」というニッチに挑む理由
- この連載で得られること

■ ポーカーとの出会い（600字）
- 個人的なポーカー体験
- 既存のポーカーコミュニティの課題
  - Twitterでは流れてしまう
  - PokerStarsのフォーラムは英語主体
  - 日本語で議論できる場がない

■ なぜ「専用SNS」という形なのか（800字）
- 汎用SNS vs 特化型の違い
- ニッチ×コミュニティの優位性
  - 特定ジャンルのユーザーは課金率が高い
  - 競合が少ない = SEOでも勝てる
- 「The Felt Table」という名前に込めた思い

■ 市場調査でわかったこと（800字）
- 国内ポーカープレイヤー人口の推移
- 既存サービスの機能マッピングと足りないもの
- Google Trendsで見るポーカー関連キーワードの動向
- AJPC/JOPTなど大会文化の成長

■ 最初の設計で決めた3つのこと（800字）
- ハンドレビュー共有を中心機能にした理由
- マネタイズ3本柱（広告・アフィリエイト・サブスク）を初日から設計
- 「ポーカー好き同士がつながれる場所」を最優先に

■ まとめ + 次回予告（400字）
- ポーカーSNSの可能性
- 次回は「ポーカーハンドレビューが上達の鍵 — 効率的な振り返り方法」
- poker_snsへのリンク（UTM付き: ?utm_source=note&utm_medium=article&utm_campaign=article_001）
- noteフォローCTA
```

## 8. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| 執筆が追いつかない（3日サイクル） | 高 | Phase A（5本分）を先行執筆してバッファ確保 |
| コード公開による脆弱性露出 | 高 | 獅白チーム事前レビュー必須、本番値は絶対に載せない |
| PVが伸びない | 中 | X連動投稿、ポーカーコミュニティへの展開、note内SEO |
| 内容が技術寄りすぎて初心者離れ | 中 | 各記事冒頭に「この記事で学べること」を明示、図解を多用 |
| 競合記事との差別化 | 中 | 「実際の収益数字を公開」で信頼性担保 |
