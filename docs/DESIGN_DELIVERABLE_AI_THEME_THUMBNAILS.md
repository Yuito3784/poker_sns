## 7. テンプレート差し替えガイド

### 7.1 新記事サムネイル作成手順

1. 記事タイトルを分析し、3パターンのうち最適なテンプレートを選択:
   - 数値変化が主題 → **Template A** (数字ビフォーアフター型)
   - 体験・エピソードが主題 → **Template B** (実録・体験談型)
   - 方法論・手順が主題 → **Template C** (戦略・ノウハウ型)

2. 該当SVGファイルをコピーし、プレースホルダーを差し替え

3. SVG → PNG (1280x670) 変換 (方法は既存ドキュメント `DESIGN_DELIVERABLE_NOTE_THUMBNAILS.md` セクション3参照)

### 7.2 タイトル文字数によるフォントサイズ調整

| タイトル合計文字数 | font-size | 行数 |
|------------------|-----------|------|
| 15文字以下 | 44px | 1行 |
| 16-30文字 | 42px | 2行 |
| 31-45文字 | 38px | 2行 |
| 46文字以上 | 34px | 3行 (非推奨) |

## 9. MEDIUM/LOW 警告 (コード変更なし)

- **[MEDIUM]** ブランドマーク `>_` はモノスペースフォント依存。PNG変換時にフォントが利用可能であることを確認すること。
- **[MEDIUM]** Template A の Before/After 数字は文字数でレイアウトが崩れる場合がある。5文字以上の場合は font-size を 60px に縮小推奨。
- **[LOW]** Template B の `{{LABEL_W}}` はSVG上で手動調整が必要。Figma/Canva利用時は自動リサイズ可能。
- **[LOW]** コードモチーフのウォーターマーク (`</>` 等) はHTMLエンティティを使用しているため、SVG直接編集時に注意。

## 11. 次記事テーマ候補へのテンプレート推奨マッピング

CEOの方針「AI・個人開発の経験則ノウハウ」に基づき、今後の記事テーマにテンプレートを割り当てる際の推奨:

| 記事テーマ方向性 | 推奨テンプレート | 理由 |
|----------------|---------------|------|
| AI導入で○○が△△に変化した | Template A | 数値変化のインパクトが最も伝わる |
| AI活用で失敗/成功した話 | Template B | ストーリー性が信頼感を醸成 |
| 個人開発のステップガイド | Template C | 構造化された情報で専門性を演出 |
| AI x 収益化の戦略 | Template C | ステップ + メトリクスで説得力向上 |
| リアルな開発日記・振り返り | Template B | 体験談ラベルで読者の共感を誘引 |
| Before/After の効率改善事例 | Template A | 数字の対比が最も効果的 |
