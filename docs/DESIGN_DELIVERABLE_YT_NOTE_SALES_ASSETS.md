|  │                                                                   │ |
|  │  LEFT 60%                         RIGHT 40%                      │ |
|  │                                                                   │ |
|  │  ┌──────────────────────┐   ┌──────────────────────┐          │ |
|  │  │ EPISODE TAG           │   │  CARD VISUALIZATION  │          │ |
|  │  │ "EP.{{NUMBER}}"       │   │                      │          │ |
|  │  │ gold chip badge       │   │  [A♠]  [K♠]         │          │ |

- `{{SITUATION}}`: 状況説明 (例: "NL200 6max / BTN vs BB")

## 6. 他チームへの連携事項

### Dev チームへ
- YouTube OEmbed埋め込み実装時、サムネイルのアスペクト比は **16:9 (1280x720)** で統一
- note CTA バナーのリンク先は既存 `/lp` ルートでOK（UTMパラメータ付き）

### DevSecOps チームへ
- CSPヘッダーへのYouTubeドメイン (`youtube.com`, `youtube-nocookie.com`) iframe許可追加が必要
- note記事内のCTAリンクは `poker-sns.com` ドメインのみ（外部リダイレクトなし）

### QA チームへ
- 各サムネイルテンプレートの納品時チェック項目:
  - [ ] ブランドカラー準拠（`#c9a84c`, `#0d1009`, `#ddd6c8`）
  - [ ] テキスト視認性（コントラスト比 4.5:1 以上）
  - [ ] プレースホルダーが全て置換されていること
  - [ ] ロゴ ♠ Poker SNS が含まれていること
  - [ ] 個人情報・機密情報が含まれていないこと

### Operations チームへ
- サムネイル制作フロー: テーマ決定 → テンプレート選択 → テキスト差し替え → QAチェック → 公開
- 推定制作時間: テンプレートからの差し替えで **15-20分/1枚**
