# Design Deliverable: ブランチ命名規則 ビジュアルフォーマット仕様

**担当**: Design 百鬼 (Senior)
**対象タスク**: ブランチ名命名規則違反の視覚化・ドキュメント補助
**ステータス**: 完了

---

## 1. 背景

スクリーンショットにて `climpire/*` 形式のブランチ名が多数確認された。
git-workflow SKILL.md で定義された `feature/*` / `fix/*` 命名規則に違反している。
Design部門として、ドキュメントやコントリビューションガイドに追加可能な視覚フォーマット仕様を提供する。

---

## 2. ブランチフロー図（ASCII）

コントリビューションガイドやREADMEに掲載可能なフロー図仕様:

```
main ─────────────────────────────────────────── (本番デプロイ専用)
  │
  └── dev ────────────────────────────────────── (統合ブランチ)
        │
        ├── feature/add-stats ──── PR → dev ──── (新機能)
        ├── feature/ui-overhaul ── PR → dev ──── (UI変更)
        ├── fix/login-error ────── PR → dev ──── (バグ修正)
        └── fix/refresh-token ──── PR → dev ──── (修正)

 [禁止] main への直接 push / commit
 [禁止] dev 上での直接実装
 [禁止] climpire/* / 任意の命名 (feature/* or fix/* 以外)
```

---

## 3. 命名規則テーブル（ドキュメント掲載用）

| プレフィックス | 用途 | 命名例 | 備考 |
|:---:|:---|:---|:---|
| `feature/` | 新機能・UI変更・リファクタ | `feature/add-stats` | `dev` から切る |
| `fix/` | バグ修正・既存挙動の修正 | `fix/login-error` | `dev` から切る |
| `main` | 本番デプロイ専用 | — | 直接変更禁止 |
| `dev` | 統合・検証 | — | PR経由のみ |

### 禁止パターン

| パターン | 理由 |
|:---|:---|
| `climpire/*` | 自動生成ハッシュ名、規則違反 |
| `hotfix/*`, `release/*` 等 | 現ワークフローでは未定義 |
| ブランチ名にスペース・日本語 | Git互換性の問題 |

---

## 4. カラーコード仕様（Git Graph等での視覚識別用）

プロジェクトのデザインシステム ("The Felt Table" Dark Luxury) に準拠:

| 要素 | 推奨カラー | 用途 |
|:---|:---|:---|
| `main` ブランチ | `#c9a84c` (Gold primary) | 本番を示す最重要ライン |
| `dev` ブランチ | `#d4b965` (Gold bright) | 統合ブランチ |
| `feature/*` | `#4a7c59` (Green accent) | 新機能の作業ブランチ |
| `fix/*` | `#7a4c4c` (Red accent) | 修正の作業ブランチ |
| 禁止ブランチ | `#4a5245` (Text muted) + 取消線 | 規則違反ブランチ |

## 5. コントリビューションガイド掲載時のレイアウト仕様

```
┌─────────────────────────────────────────────────────┐
│  ## ブランチ命名規則                                    │
│                                                       │
│  ┌───────────────────────────────────────────────┐   │
│  │  [フロー図: セクション2のASCII図]                 │   │
│  └───────────────────────────────────────────────┘   │
│                                                       │
│  ┌───────────────────────────────────────────────┐   │
│  │  [テーブル: セクション3の命名規則テーブル]         │   │
│  └───────────────────────────────────────────────┘   │
│                                                       │
│  ┌───────────────────────────────────────────────┐   │
│  │  [注意ボックス: 禁止パターン一覧]                 │   │
│  └───────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

- フォント: プロジェクト標準（monospace for branch names）
- 背景: `#131a14` (Surface)
- ボーダー: `#1f2a1e` (Border)
- テキスト: `#ddd6c8` (Text primary)
- 注意ボックス背景: `#1a1a10` with `border-left: 3px solid #c9a84c`

## 7. 所見

Design領域からの補足:
- 現在のスクリーンショットに映っている Git Graph のブランチ名は、視覚的にもタスクIDハッシュ値のみで意味が読み取れない。`feature/*`/`fix/*` プレフィックスに統一することで、Git Graph上でもブランチの目的が一目で識別可能になる。
- 上記フォーマット仕様はDevチームの命名規則修正完了後、ドキュメントに組み込み可能。必要時に声をかけてください。
