# Operations: ターゲットアカウントリスト運用ランブック

## 概要
poker_sns潜在ユーザーリスト（Xアカウント100件）の運用・管理・更新手順を定義する。

## ファイル管理

### 出力先
```
~/Desktop/poker_sns_ops/
```

### 命名規則
```
target_accounts_YYYYMMDD.csv
```
- 日付は更新実施日を使用
- 旧版は同フォルダ内に保持（上書き禁止）

### ファイル仕様
| 項目 | 仕様 |
|---|---|
| エンコーディング | BOM付きUTF-8 |
| 区切り | カンマ (CSV) |
| カラム | `@ユーザーID`, `ユーザー名`, `プロフィール概要`, `カテゴリ`, `ステータス` |

## カテゴリ定義

| カテゴリ | 説明 | 初期配分目安 |
|---|---|---|
| プロポーカープレイヤー | 国内外のプロ選手 | 20-25件 |
| ポーカー配信者・YouTuber | 動画配信メイン | 8-10件 |
| アミューズメント店舗 | 国内アミューズメントポーカー店 | 15-20件 |
| トーナメント運営 | 大会主催者 | 3-5件 |
| 団体・連盟 | ポーカー協会等 | 2-3件 |
| ポーカーメディア | ニュース・情報メディア | 20-25件 |
| ポーカー学習 | 戦略・教育コンテンツ | 5-8件 |
| ポーカーサービス・アプリ | オンラインポーカー等 | 5-10件 |
| ポーカーコミュニティ | コミュニティ運営 | 3-5件 |
| その他 | 上記に該当しない関連アカウント | 適宜 |

## ステータス管理

| ステータス | 説明 | 次アクション |
|---|---|---|
| `未連絡` | 初期状態。まだDM・メンション未実施 | DM送信 |
| `DM済` | DMを送信済み。返信待ち | 3営業日後にフォローアップ |
| `返信あり` | 先方から返信を受領 | 内容に応じて対応 |
| `登録済` | poker_snsへのユーザー登録を確認 | リストから卒業候補 |
| `見送り` | アプローチ対象外と判断 | 理由をプロフィール概要列に追記 |

## 更新サイクル

### 月次更新（毎月第1月曜日）
1. 既存リストのステータス棚卸し
   - 全件の`ステータス`列を最新化
   - `登録済`・`見送り`を除外し、新規候補で補充（常時100件維持）
2. 新規アカウント調査
   - X検索で「ポーカー」「poker」「テキサスホールデム」等のキーワード調査
   - 新規フォロワー増加アカウントを優先追加
3. 新版CSV出力
   - `target_accounts_YYYYMMDD.csv` として新規ファイル作成
   - 旧版はアーカイブとして残す

### 週次チェック（毎週月曜日）
- `DM済`アカウントの返信有無確認
- `返信あり`アカウントの対応状況確認
- ステータス更新（CSV直接編集）

## KPIトラッキング

| 指標 | 目標 | 測定方法 |
|---|---|---|
| DM送信率 | 100件/月 | ステータス`DM済`以降の累計 |
| 返信率 | 10%以上 | `返信あり` / `DM済` |
| 登録転換率 | 3%以上 | `登録済` / `DM済` |
| リスト鮮度 | 常時100件 | `未連絡`+`DM済`+`返信あり`の合計 |

## 注意事項
- Web検索ベースの調査のため、`@ユーザーID`は実際のXアカウントと異なる可能性あり
- 実運用前に各IDのX上での存在確認を実施すること
- 店舗系・メディア系は推定IDを含むため特に注意
- DM送信はXの利用規約に準拠し、過度な一斉送信は避けること
