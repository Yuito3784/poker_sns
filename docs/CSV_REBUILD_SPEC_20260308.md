## 3. 新CSVカラム仕様

| カラム | 型 | 説明 | データソース |
|---|---|---|---|
| @ユーザーID | text | Xのユーザー名（@付き） | X API `username` |
| ユーザー名 | text | X表示名 | X API `name` |
| プロフィール概要 | text | Xプロフィール欄そのまま | X API `description` |
| フォロワー数 | integer | フォロワー数 | X API `public_metrics.followers_count` |

| ステータス | text | `未連絡` 固定（初期状態） | 固定値 |

**変更点**: 「フォロワー数」カラムを追加（フィルタ要件の検証容易化）

## 4. データ取得フロー

```
Step 1: キーワード検索
  → ポーカー関連キーワードでX検索
  → 日本語アカウント優先（location: Japan or bio内日本語）

Step 2: フォロワーフィルタ
  → followers_count < 1000 のみ抽出
  → verified アカウントも除外（インフルエンサー除外強化）

Step 3: アカウント検証
  → 凍結/削除/非公開アカウント除外
  → 直近30日以内にポスト実績があるアクティブアカウントのみ

Step 4: プロフィール取得
  → X API bio をそのまま「プロフィール概要」に記載
  → AI加工・要約は行わない

Step 5: カテゴリ分類
  → bio内容に基づきランブック定義カテゴリに自動/手動分類

Step 6: バリデーション
  → 重複チェック（username一意性）
  → 空欄チェック（bio空でも可、ただしフラグ付与）
  → フォロワー数 < 1000 再確認
```

## 6. 除外条件

以下に該当するアカウントは除外:

- フォロワー数 >= 1000
- verified（認証バッジ付き）
- 企業公式アカウント（大手のみ: GGPoker, PokerStars, JOPT等）
- プロポーカープレイヤー（WSOP/WPT/EPT入賞実績あり）
- 30日以上アクティビティなし
- 凍結/削除/非公開
- bot判定（投稿パターンが機械的）
