## 1. 目的

X（@poker93626）のSNS運用によるpoker_snsユーザー獲得の効果を定量的に計測・可視化し、週次レビューで改善サイクルを回す。

---

## 2. KPI体系

### 2.1 North Star Metric

**poker_snsへのX経由新規登録数（月間）**

### 2.2 KPIツリー

```
月間売上100万円
  └─ 月間アクティブユーザー数（MAU）
       └─ 新規ユーザー獲得数
            └─ X経由流入数
                 ├─ インプレッション数
                 │    └─ 投稿数 × 平均インプレッション
                 ├─ エンゲージメント率
                 │    └─ (いいね+RT+リプ+クリック) / インプレッション
                 └─ CVR（流入→登録）
                      └─ UTM経由LP訪問 → 登録完了
```

### 2.3 KPI目標値（段階別）

| KPI | Month 1 | Month 3 | Month 6 |
|-----|---------|---------|---------|
| フォロワー数 | 100 | 500 | 2,000 |
| 月間インプレッション | 10,000 | 100,000 | 500,000 |
| エンゲージメント率 | 3% | 5% | 5% |
| プロフィールクリック/月 | 50 | 500 | 2,000 |
| X経由サイト流入/月 | 30 | 300 | 1,500 |
| X経由新規登録/月 | 5 | 50 | 300 |
| CVR（流入→登録） | 15% | 15% | 20% |

## 3. データソースと計測方法

### 3.1 データソース一覧

| データソース | 計測項目 | 取得方法 |
|------------|---------|---------|
| **X Analytics** | インプレッション、エンゲージメント、フォロワー推移 | X Analytics ダッシュボード or API |
| **SocialDog** | フォロワー分析、最適投稿時間、投稿パフォーマンス | SocialDog管理画面 |
| **GA4** | UTM経由流入数、セッション数、ページビュー | GA4ダッシュボード |
| **poker_sns DB** | 新規登録数（utm_source=twitter） | バックエンドAPI / SQL |
| **Stripe** | X経由ユーザーの課金転換 | Stripe Dashboard |

### 3.2 UTMパラメータ設計（X運用専用）

| パラメータ | 値 | 用途 |
|-----------|-----|------|
| `utm_source` | `twitter` | X経由を識別 |
| `utm_medium` | `social` | SNS流入 |
| `utm_campaign` | `daily_tips` / `service_intro` / `news` / `community` / `entertainment` | 投稿カテゴリ別効果測定 |
| `utm_content` | `{YYYYMMDD}_{連番}` | 個別投稿の効果追跡 |

### 3.3 GA4イベント設計

| イベント名 | トリガー | パラメータ |
|-----------|---------|-----------|
| `utm_landing` | UTMパラメータ付きページ訪問 | source, medium, campaign, content |
| `signup_complete` | 新規登録完了 | utm_source（取得できれば） |
| `premium_upgrade` | プレミアム登録 | utm_source |

## 5. 週次レビュープロセス

### 5.1 レビュースケジュール

| 曜日 | 時間 | 内容 |
|------|------|------|
| 毎週月曜 | 10:00 | 先週KPIレビュー + 今週投稿計画策定 |

### 5.2 週次レビューアジェンダ

```
1. 先週のKPI実績 vs 目標（5分）
   - フォロワー増減
   - インプレッション合計
   - エンゲージメント率
   - X経由サイト流入・登録数

2. Top/Bottom投稿分析（5分）
   - 最もエンゲージメントが高かった投稿3本 → 成功要因
   - 最もエンゲージメントが低かった投稿3本 → 改善点

3. 今週の投稿計画（5分）
   - トピック選定
   - カテゴリ配分調整
   - 特別イベント・キャンペーン確認

4. アクションアイテム確認（5分）
```
