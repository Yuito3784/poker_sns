# note記事テーマ軸シフト KPIトラッキングシート

**作成日**: 2026-03-02
**担当**: Operations (白上)
**目的**: note記事のテーマをポーカー中心 → AI×個人開発×CEO経験則ノウハウへシフトした前後の効果を定量比較する

---

## 1. テーマ軸シフト概要

### 1.1 シフト前（旧テーマ）
- ポーカー戦略（GTO、オッズ計算、トーナメント攻略）
- poker_snsサービス紹介
- ポーカーコミュニティ話題

### 1.2 シフト後（新テーマ）— CEO方針
- AI活用ノウハウ（AI×SNS運用、AI導入効果、AI投稿自動化）
- 個人開発の経験則（MVP構築、技術選定、1人運用）
- マネタイズ実践（フォロワー少数でも稼ぐ方法、導線設計）
- 失敗談・実録ベースのストーリー

### 1.3 過去記事タイトルの傾向分析

CEOが既に公開済みの記事タイトルのパターン:

| パターン | 出現回数 | 例 |
|---------|---------|-----|
| 【実録】/ 【体験談】 | 3 | 「1年で150万溶かした私が…」 |
| 数字入りフック | 8 | 「月3万円」「6件→27件」「週11時間」 |
| AI × 成果物 | 6 | 「AI導入初月に…」「AI投稿のインプレ…」 |
| フォロワー数明示 | 3 | 「フォロワー200人台で」「フォロワー500人時点」 |
| 仮定形フック | 1 | 「【もしも】今フォロワー0なら…」 |

**共通要素**: 実体験ベース + 具体数値 + AI/SNSマネタイズ
**ポーカー関連**: 0件 ← CEOの既存記事はポーカーに寄っていない

## 5. 効果判定基準

### 5.1 テーマシフト成功判定

| 指標 | 成功(GREEN) | 要改善(YELLOW) | 失敗(RED) | 判定タイミング |
|------|-----------|--------------|----------|-------------|
| 平均PV/記事 | Baseline比 120%+ | Baseline比 80-119% | Baseline比 80%未満 | Phase 1終了時 |
| 平均スキ/記事 | Baseline比 110%+ | Baseline比 70-109% | Baseline比 70%未満 | Phase 1終了時 |
| noteフォロワー増 | 月+50以上 | 月+20-49 | 月+20未満 | 月次 |
| poker_sns流入 | 月30+クリック | 月10-29 | 月10未満 | 月次 |
| 有料記事売上 | 月¥3,000+ | 月¥1,000-2,999 | 月¥1,000未満 | Phase 2以降 |

### 5.2 判定後アクション

| 判定 | アクション |
|------|----------|
| GREEN | 現行テーマ配分を継続。成功パターンを強化 |
| YELLOW | カテゴリ別データを分析し、反応の良いカテゴリに比重をシフト |
| RED | タイトル・フック構造を見直し。CEOの過去成功記事パターンを再分析 |
