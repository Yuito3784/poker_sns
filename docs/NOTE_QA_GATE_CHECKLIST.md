## 5. 判定基準

| 判定 | 条件 |
|------|------|
| **PASS** | 全チェック項目が合格、または軽微な指摘のみで修正済み |
| **CONDITIONAL PASS** | 軽微な指摘が1-2件残るが公開に支障なし（公開後修正可） |
| **FAIL** | セキュリティ項目に1件でも不合格、またはQA重大指摘が未修正 |

**FAIL の場合**: 公開を1日延期し、修正後に再レビュー。
