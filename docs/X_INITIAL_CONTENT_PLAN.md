## 2. 投稿ガイドライン

### トーン
- プロフェッショナルかつフレンドリー
- ポーカー用語を自然に使用（初心者向け投稿では簡単な解説を添える）
- 絵文字は最小限（スペード/ハート/ダイヤ/クラブのスーツ記号のみ許可）

### フォーマットルール
- 1投稿140文字以内を基本（視認性重視）
- ハッシュタグは2-4個/投稿
- CTA投稿にはUTM付きリンクを含める
- 画像付き投稿は週3回以上を目標

### 固定ハッシュタグ
`#ポーカー` `#poker` `#PokerSNS` `#テキサスホールデム`

### カテゴリ別追加タグ
- Tips/戦略: `#GTO` `#ポーカー戦略`
- ハンドレビュー: `#ハンドレビュー` `#ポーカーハンド`
- 業界: `#JOPT` `#WSOP` `#ポーカー大会`
