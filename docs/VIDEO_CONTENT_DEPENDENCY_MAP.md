## 6. 動画テンプレート構成仕様（V-02用、Design仕様書V-01と連動）

| セクション | 秒数 | 内容 | デザイン要素 |
|-----------|------|------|------------|
| 導入 | 0-5秒 | 「今日のハンドレビュー」+ ハンド概要テロップ | タイトルカード（背景#0d1009、テキスト#c9a84c） |
| プリフロップ | 5-15秒 | ポジション・ハンド・アクション | カード画像 + ローワーサード（ポジション表示） |
| フロップ | 15-25秒 | ボード表示 + アクション解説 | コミュニティカード + ベットサイズ表示 |
| ターン/リバー | 25-40秒 | 展開 + 判断ポイント | ハイライト演出 + テキスト注釈 |
| 結論 | 40-55秒 | ベストプレイ解説 | まとめテロップ |
| CTA | 55-60秒 | poker_sns誘導 | エンドカード（QRコード + URL + ゴールドCTA） |

### デザイン仕様（The Felt Table準拠）
- 解像度: 1080x1920px（9:16）
- 背景色: #0d1009
- テキスト主色: #ddd6c8（warm ivory）
- アクセント: #c9a84c（gold）
- フォント: Noto Sans JP（本文）、Playfair Display（タイトル）
- テキスト安全領域: 上下左右各10%マージン
- CTA配置: 画面下部20%エリア
