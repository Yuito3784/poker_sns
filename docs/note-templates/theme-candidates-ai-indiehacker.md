## poker_snsへの導線設計

記事内でのサービス紹介は以下のルールに従う:

| ルール | 詳細 |
|--------|------|
| 記事冒頭には入れない | 最初はノウハウに集中。宣伝感を消す |
| 記事末尾のCTA | 「この記事で紹介した仕組みを実際に使っているサービスはこちら」程度の自然な導線 |
| 具体例としての言及 | 「実際に自分が作ったSNSでは〜」と体験の一部として自然に触れる |
| 有料記事の場合 | 無料パートでノウハウ、有料パートで具体的なコード・設定値を公開 |
