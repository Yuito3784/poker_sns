| パターン | 出現回数 | 効果 |

### 1.3 タイトル構造テンプレート

過去タイトルから抽出した高パフォーマンス構造:

```
構造A: 【ラベル】[状況/数字] + [変化/結果] + [方法/理由]
例: 【実録】1年で150万溶かした私が、AI導入初月に回収するまでの全記録

構造B: [逆説的な事実] + [具体手法]
例: 「投稿数は半分、反応は3倍」にしたAIマーケの全工程

構造C: [具体フェーズ] + [達成したこと] + [裏側/仕組み]
例: 【フォロワー1,200人時点】月5万円生まれた導線の裏側
```

## 2. スコアリング基準

新テーマ候補タイトルを以下の基準で5段階評価する。

| 基準 | 配点 | 評価内容 |
|------|------|---------|
| **具体数字の有無** | 0-5 | 金額・人数・時間など具体的な数値が含まれるか |
| **リアリティワード** | 0-5 | 実録/体験談/実データなど、体験ベースを示す語があるか |
| **ビフォーアフター** | 0-5 | 変化が明確に伝わるか (A→B構造) |
| **ターゲット訴求力** | 0-5 | AI×個人開発に興味がある層に刺さるか |
| **行動喚起力** | 0-5 | 読者が「自分もやりたい」と思えるか |
| **CEO経験ベース** | 0-5 | CEOの実体験に基づいた語れるテーマか |

**合格ライン**: 24点以上 / 30点満点
