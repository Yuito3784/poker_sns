## 4. KPI改善アクション

| CTR/CVRが目標未達の場合 | 改善施策 |
|------------------------|---------|
| CTR < 2% | バナーデザイン変更、配置位置見直し、CTA文言テスト |
| CVR < 3% | ランディングページの最適化提案をパートナーに依頼、特典訴求強化 |
| クリック数 < 50/月 | パートナーの露出枠追加、note記事内での自然な言及 |

## 6. 計測実装要件

現在の実装状態:
- `AffiliatePartner.clickCount`: 実装済み（リダイレクト時にインクリメント）
- 表示回数(impression): **未実装** → Phase 2で計測APIを追加予定
- CVR計測: パートナー側ダッシュボードに依存

**Phase 2 追加計測項目**:
- impression count per partner per page
- click-through by placement (sidebar vs partner page vs feed)
- UTM parameter tracking for each partner link
