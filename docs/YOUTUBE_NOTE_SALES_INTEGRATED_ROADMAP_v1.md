## 1. YouTube展開企画

### 1.1 チャンネル設計

| 項目 | 内容 |
|------|------|
| チャンネル名 | Poker SNS |
| ブランドカラー | ゴールド(#c9a84c) × ダークグリーン(#0d1009) |
| ターゲット | 日本のポーカープレイヤー（初中級者メイン） |
| ポジショニング | 「ポーカー戦略×コミュニティ」解説チャンネル |

### 1.2 コンテンツ戦略

| コンテンツ種別 | 形式 | 投稿頻度 | 目的 |
|--------------|------|---------|------|
| Shorts（ハンド解説） | 60秒 縦型 | 週3-5本 | リーチ拡大・チャンネル認知 |
| 戦略解説動画 | 5-10分 横型 | 月2本 | SEO+権威性+poker_sns誘導 |
| 機能紹介・使い方 | 3-5分 横型 | 月1本 | 直接的なユーザー獲得 |
| ライブ配信（将来） | 30-60分 | 月1回 | コミュニティ形成 |

### 1.3 Shortsコンテンツテンプレート

```
構成（60秒以内）:
[0-5秒] フック: 「このハンド、あなたならどうする？」
[5-25秒] シチュエーション説明（テーブル、ポジション、ハンド）
[25-45秒] 判断ポイント + 結果
[45-55秒] 解説・ポイント
[55-60秒] CTA: 「詳しくはPoker SNSで議論しよう」
```

## 7. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| YouTube登録者が伸びない | 中 | Shortsの投稿頻度UP、X連携拡散、ポーカーコミュニティへの告知 |
| 営業返信率が低い（<10%） | 中 | ターゲット拡大50社、報酬条件見直し、紹介経由アプローチ |
| note記事PVが伸びない | 中 | SEOキーワード見直し、X連動投稿、note内のSEO最適化 |
| 動画制作のリソース不足 | 高 | テンプレート化で効率化、最初はテキストベースShortsで最小工数 |
| 広告主の効果期待値とのギャップ | 高 | 初回は割引価格で提供、詳細なレポートで信頼構築 |
| CSPヘッダー変更によるセキュリティ影響 | 低 | 最小限のドメイン許可、DevSecOpsレビュー必須 |
