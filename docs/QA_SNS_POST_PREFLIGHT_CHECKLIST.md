# QA/QC SNS投稿プリフライトチェックリスト

**Version:** 1.0
**Author:** QA/QC (尾丸)
**Date:** 2026-03-07
**対象:** X (@poker93626) 運用投稿 + 将来的にYouTube・note展開時も適用

---

## 1. 目的

SNS投稿の品質を担保し、ブランド毀損・リンク切れ・トラッキング不全を防止する。
全投稿は公開前にこのチェックリストを通過すること。

---

## 2. 投稿前チェックリスト（全4項目）

### 2.1 テキスト品質チェック

| # | チェック項目 | 判定 |
|---|-------------|------|
| T-1 | 誤字・脱字がないこと | [ ] |
| T-2 | ポーカー用語のスペルが正しいこと（例: All-in, Flop, Turn, River） | [ ] |
| T-3 | ハッシュタグが正しい形式で挿入されていること（#ポーカー #poker 等） | [ ] |
| T-4 | メンション先が正しいアカウントであること | [ ] |
| T-5 | 投稿文字数がプラットフォーム上限内であること（X: 280文字 / 日本語は140文字） | [ ] |
| T-6 | 機密情報（パスワード・内部URL・API Key等）が含まれていないこと | [ ] |

### 2.2 リンク検証チェック

| # | チェック項目 | 判定 |
|---|-------------|------|
| L-1 | 本文中のURLがHTTPステータス200を返すこと | [ ] |
| L-2 | URLがHTTPS（非HTTP）であること | [ ] |
| L-3 | リンク先ページが正しいコンテンツを表示すること（目視確認） | [ ] |
| L-4 | 短縮URLを使用する場合、展開先が正しいこと | [ ] |

### 2.3 UTMパラメータチェック

| # | チェック項目 | 判定 |
|---|-------------|------|
| U-1 | `utm_source` が正しいこと（例: `twitter`, `youtube`, `note`） | [ ] |
| U-2 | `utm_medium` が正しいこと（例: `social`, `video`, `article`） | [ ] |
| U-3 | `utm_campaign` が設定されていること（例: `daily_tips_2026w10`） | [ ] |
| U-4 | UTMパラメータ付きURLでアクセスし、GA4でリアルタイムにイベントが記録されること | [ ] |
| U-5 | UTMパラメータがURL中で正しくエンコードされていること（&が二重エスケープされていない等） | [ ] |

#### UTMパラメータ命名規則

```
utm_source:   twitter | youtube | note | line | discord
utm_medium:   social | video | article | share
utm_campaign: {category}_{YYYY}w{WW}
              例: daily_tips_2026w10, hand_analysis_2026w10
```

### 2.4 OGPカード表示チェック

| # | チェック項目 | 判定 |
|---|-------------|------|
| O-1 | X Card Validator（またはポスト下書きプレビュー）でカードが正しく展開されること | [ ] |
| O-2 | og:title が期待値と一致すること | [ ] |
| O-3 | og:description が期待値と一致すること（切り捨てなし） | [ ] |
| O-4 | og:image が表示され、解像度が十分であること（1200x630px推奨） | [ ] |
| O-5 | twitter:card が `summary_large_image` であること | [ ] |
| O-6 | リンク先ページの `<meta>` タグにog:url, og:site_name が含まれること | [ ] |

## 5. NG時の対応フロー

1. **CRITICAL**（機密情報含有 / リンク先がエラーページ）: 即時投稿中止。修正後に再チェック。
2. **HIGH**（UTM欠落 / OGPカード非表示）: 修正後に再チェック。修正不可の場合はリンクなし版で投稿。
3. **MEDIUM**（誤字1箇所 / ハッシュタグ不備）: 修正して投稿。
4. **LOW**（og:descriptionの軽微な差異）: 記録のうえ投稿。次回修正。
