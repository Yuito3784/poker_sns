## 1. サービス概要

**Poker SNS** は、ポーカープレイヤー向けの日本初・特化型ソーシャルネットワーキングサービスです。

| 項目 | 内容 |
|------|------|
| サービス名 | Poker SNS |
| ジャンル | ポーカー特化型SNS |
| 対象ユーザー | ポーカープレイヤー（初心者〜上級者）、ポーカー系インフルエンサー |
| 主要機能 | 投稿・タイムライン、ハッシュタグ、リプライ、ブックマーク、リポスト、フォロー、ブロック/ミュート、プロフィール |
| プレミアム機能 | AI戦略分析、投稿文字数拡張(1000文字)、広告非表示、統計ダッシュボード |
| 対応デバイス | PC / スマートフォン（レスポンシブWebアプリ） |
| URL | ※本番デプロイ後に記載 |

- **可処分所得**: 中〜高（ポーカーバンクロール管理の習慣あり）
- **デジタルリテラシー**: 高（オンラインポーカー利用者）

- **情報感度**: 高（戦略・確率論への関心、自己投資意欲）

## 4. 広告メニュー

### 4.1 フィード内広告

| 項目 | 内容 |
|------|------|
| 配置 | タイムライン（ホーム・トレンド・検索結果）内、3投稿ごとに1枠 |
| フォーマット | タイトル + 説明文 + 画像(16:9) + リンクURL |
| ラベル | 「広告」バッジ付きで明確に区別 |
| 対象 | 無料ユーザー（プレミアム会員には非表示） |

### 4.2 サイドバーバナー

| 項目 | 内容 |
|------|------|
| 配置 | PC版右サイドバー、おすすめセクション |
| フォーマット | ロゴ + パートナー名 + 短い説明 + リンク |
| 表示件数 | 1〜3件（ローテーション） |

### 4.3 LP・特集ページ

| 項目 | 内容 |
|------|------|
| 配置 | `/partners` ページ内カテゴリ別セクション |
| フォーマット | ロゴ + 詳細説明 + 特典情報 + CTA |
| 特徴 | カテゴリ別整理（ポーカールーム / ツール / 学習 / グッズ） |

## 7. 掲載基準

以下に該当する広告は掲載不可とします。

1. リアルマネーギャンブル（日本国内法規制に抵触するもの）
2. 違法・半違法サービス
3. 著しく誇大な表現を含むもの
4. ユーザー体験を著しく損なうもの（全画面・自動再生動画等）
5. 競合SNSサービスの広告
