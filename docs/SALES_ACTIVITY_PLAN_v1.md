## 5. 営業プロセス

### 5.1 営業フロー詳細

```
[Week 1]
  ├─ リスト精査 → 上位10社選定
  ├─ 各社の担当者/連絡先特定
  └─ DM/メールテンプレート最終化

[Week 2]
  ├─ Tier 1 上位5社にDM送信
  ├─ Tier 2 上位5社にメール送信
  └─ 営業資料デッキv1完成

[Week 3]
  ├─ 返信対応・オンラインMTG設定
  ├─ 残りTier 1-2 10社にアプローチ
  └─ Tier 3 5社にアプローチ

[Week 4]
  ├─ 提案・条件交渉
  ├─ 初成約目標
  └─ 効果測定体制構築

[Month 2以降]

  ├─ 未返信先へのフォローアップ
  ├─ 新規ターゲット追加

```

## 6. KPI管理

### 6.1 営業ファネル KPI

```
アプローチ数（30件/月）
    ↓ 返信率 15%
返信数（4-5件/月）
    ↓ MTG設定率 60%
MTG数（3件/月）
    ↓ 提案率 80%
提案数（2-3件/月）
    ↓ 成約率 50%
成約数（1-2件/月）
```

## 7. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| DAU/MAU不足で広告価値を訴求できない | 高 | 初期は割引価格で実績作り、ニッチ市場の高親和性を訴求 |
| 返信率が低い（<10%） | 中 | ターゲット拡大、紹介経由アプローチ、SNSでの関係構築 |
| 広告効果が低い | 中 | A/Bテスト、配置最適化、ネイティブ広告形式の改善 |
| 賭博法関連のコンプライアンス懸念 | 高 | リアルマネー機能なし、「スキルゲーム/戦略」ポジショニング |
| 競合メディアの台頭 | 低 | ポーカー特化×SNSの独自性で差別化 |
